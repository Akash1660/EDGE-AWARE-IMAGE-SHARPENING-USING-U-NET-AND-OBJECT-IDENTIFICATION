# Edge-Aware Image Sharpening using U-Net with Knowledge Distillation

## Overview

Edge-Aware Image Sharpening is a lightweight deep learning framework designed to restore sharpness in blurred images while preserving fine details and edges. The system combines a compact U-Net architecture with edge detection and image segmentation cues, and leverages knowledge distillation to train an efficient student model suitable for real-time applications and edge-device deployment.

### Key Features

* Lightweight U-Net architecture (~3.8M parameters)
* Edge-aware image restoration using Sobel edge maps
* HSV-based segmentation guidance
* Knowledge distillation from a high-capacity teacher network
* High image quality with low computational cost
* Real-time inference capability for resource-constrained devices

---

## Model Architecture

### Input

A 5-channel tensor consisting of:

* RGB Blurred Image (3 channels)
* Sobel Edge Map (1 channel)
* HSV Segmentation Mask (1 channel)

### Output

* Sharpened RGB Image (3 channels)

### Network

* Encoder–Decoder U-Net Architecture
* Skip Connections for feature preservation
* Approximately 3.8 Million Parameters

---

## Training Strategy

The model employs **Knowledge Distillation (KD)**, where a large teacher U-Net transfers its learned knowledge to a smaller student U-Net.

### Loss Function

Hybrid Loss:

Loss = 0.4 × MSE + 0.6 × (1 − SSIM)

where:

* MSE = Mean Squared Error
* SSIM = Structural Similarity Index Measure

---

## Dataset

### DIV2K Dataset

Training images are generated by applying synthetic Gaussian blur to high-resolution images.

**Blur Settings:**

* Kernel Size: 21 × 21
* Sigma (σ): 2.5

## Performance

| Metric       | Value    |
| ------------ | -------- |
| SSIM         | 0.9469   |
| PSNR         | 28.63 dB |
| Average Loss | 0.0347   |

### Comparison with Existing Methods

| Method              | PSNR (dB) | SSIM       | Model Size (M) |
| ------------------- | --------- | ---------- | -------------- |
| Standard U-Net      | 26.5      | 0.920      | 8.5            |
| Multi-Scale CNN     | 27.8      | 0.930      | 18.4           |
| Ahn et al. (KD)     | 27.1      | 0.910      | 4.2            |
| **Proposed Method** | **28.63** | **0.9469** | **3.8**        |

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/edge-aware-image-sharpening.git
cd edge-aware-image-sharpening
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Training

```bash
python train.py \
    --data_dir /path/to/DIV2K_images \
    --save_path checkpoints/unet_edge_seg.pt \
    --epochs 300
```

---

## Inference

```bash
python test.py \
    --model_path checkpoints/unet_edge_seg.pt \
    --input_dir /path/to/test_images \
    --output_dir results/
```
